# 我的账本 v2

一款面向手机的个人记账网页应用：纯前端、离线可用、数据只保存在本机浏览器。
适合添加到 iPhone 主屏幕当 App 用，也可以放在 GitHub Pages 上访问。

## 主要功能

**记账**
- 支出 / 收入 / 账户间转账
- 两步式记账面板：金额键盘（支持 + − × ÷ 计算）→ 图标准分类 → 保存
- 分类、账户、日期、备注、重复记账
- 账单编辑、复制、删除
- 明细搜索（分类 / 备注 / 账户）、按月份或全部、按类型、按账户筛选

**预算**
- 每月总预算 + 使用进度
- 分类预算（餐饮、交通等单独设上限，超支标红）
- 剩余额度、日均可用、已用比例
- 沿用上月预算

**统计**
- 统计周期：本周 / 本月 / 近 3 个月 / 近半年 / 自定义起止日期（按自然周、自然月）
- 可前后翻页查看任意历史周期（翻页后为完整周期）
- 支出构成环形图 + 分类排行（金额、占比、条形）
- 收入构成
- 近 6 个月收支柱状图，点柱子可直接查看该月
- 区间支出柱状图：本周/本月按天、近 3 个月按周、近半年按月自动切换
- 与上一周期对比（环比）

**活动费用 AA**
- 活动名称、总金额、参与人数、额外收取
- 自动计算每人 AA、应收合计、含额外人均
- 收款登记、未收提醒、收款历史、撤销上一次收款
- 活动编辑、删除、导出 CSV

**借还**
- 借出 / 借入、还款进度、历史记录
- 快捷还款（全部 / 一半）、撤销上一次还款
- 借还编辑、删除，待收待还汇总

**账户与资产**
- 账户余额 = 初始余额 + 收入 − 支出 ± 转账
- 资产总览：各账户余额、借出待收、借入待还、净资产

**个性化**
- 深色 / 浅色 / 跟随系统，深色下可切「纯黑（OLED）」
- 10 种预设主题色 + 任意自定义主题色
- 6 套背景（默认渐变 / 纯色 / 纸纹 / 薄荷 / 日落 / 夜蓝），跟主题色联动
- 16 种字体、自定义文字颜色
- 隐藏金额（隐私模式）
- 自定义分类与图标（内置 90+ 图标），列表与记账面板统一图标底色

**视觉与交互**
- 金额等宽数字、千分位，切换页面时数字滚动到位
- 支出日历热力图：按当天金额深浅着色，点某天看当天账单
- 环形图分段留缝、柱状图网格与高光、每日支出对数式缩放
- 底部导航滑动指示器、面板弹性动画、列表逐条淡入、按压反馈

**安全与数据**
- 4 位数字密码锁（SHA-256 存储），离开后自动锁定
- JSON 完整备份 / 恢复（可合并或覆盖）、CSV、Excel 导出
- 自动历史快照（最多 5 份，可回滚）
- PWA：可添加到主屏幕、离线打开

## 统计周期说明

统计按**自然周期**计算，不是滚动天数：

| 选项 | 区间 |
| --- | --- |
| 本周 | 本周一 00:00 到今天（周一至周日为一整周） |
| 本月 | 本月 1 日到今天 |
| 近 3 个月 | 前两个完整自然月的 1 日到今天，共 3 个自然月 |
| 近半年 | 前五个完整自然月的 1 日到今天，共 6 个自然月 |
| 自定义 | 手动选择开始 / 结束日期 |

当前周期只统计到今天；用左右箭头前后翻页时，翻到的是**完整**的上一个周期：

- 本周 ← 上一周（周一至周日完整 7 天）← 再上一周 …
- 本月 ← 上一个完整自然月（1 日至月末）…
- 近 3 个月 ← 再往前 3 个完整自然月（例如 5/1–7/31）…
- 近半年 ← 再往前 6 个完整自然月 …

例如今天是周五，「本周」显示周一至周五；点一次左箭头，显示上周一至上周日（完整一周）。
「近 6 个月收支」始终显示截至当前区间末尾月份的 6 个自然月，点击柱子会切到该月。

## 数据说明
- 所有数据存放在当前浏览器的 `localStorage`，不上传服务器，也不进入 GitHub。
- 换设备、换浏览器、清理浏览器数据前，请先在「设置 → 数据」导出 JSON 备份。
- 旧版（v1 / v2 存储结构）数据会在首次打开时自动迁移，无需手动处理。
- 密码锁只能防住"随手打开"，无法加密本地数据；忘记密码无法找回，只能清空。

## 部署到 GitHub Pages
1. 在 GitHub 新建公开仓库，例如 `my-ledger`。
2. 把 `index.html`、`style.css`、`app.js`、`manifest.json`、`sw.js`、`README.md` 和 `icons/` 目录上传到仓库根目录。
3. 仓库 Settings → Pages → Build and deployment 选 `Deploy from a branch`。
4. Branch 选 `main`，目录选 `/(root)`，保存。
5. 访问 `https://你的用户名.github.io/my-ledger/`。

## 添加到 iPhone 主屏幕
1. 用 Safari 打开上面的网址。
2. 点分享按钮 → 「添加到主屏幕」。
3. 名称可设为「我的账本」，点击添加。之后从主屏幕打开就是全屏无地址栏。

## 更新版本注意
改完前端文件后，请把 `sw.js` 里的 `CACHE = "my-ledger-v2-4"` 末尾数字加 1，
并把 `index.html` 里 `style.css?v=23`、`app.js?v=23` 的版本号同步加 1，
这样手机和桌面浏览器才会拿到新版本，而不是缓存里的旧文件。

## 兼容性
- iOS Safari 15.4+ / Android Chrome / Edge / Chrome 桌面版
- 深色模式跟随系统需要 iOS 13+
- 计算器式金额键盘为自绘，不依赖系统键盘
